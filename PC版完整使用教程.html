mGBAx · Windows 移植版

PC 版完整使用教程

mGBAx 是 mGBA 模拟器的 Windows 移植版，可运行 GBA / GBC / GB 游戏。界面沿用 mGBA 桌面版（菜单为英文），额外加入「模拟器增强」面板——核心是倍速音乐：快进刷级时，音乐不再被磁带式升调带跑。

Windows 10/11 · 64 位免安装支持 .gba / .gbc / .gb / .zip无需 VC++ 运行库

1安装与运行

整个程序就是 mGBAx.exe 一个文件（约 98 MB），不需要安装，双击即可运行，也可以直接放 U 盘带到别的电脑。Qt、SDL、解码库等依赖都已打包进去，不需要额外装 .NET / VC++ 运行库，也不需要配套文件夹。

事项说明
首次启动约 3～10 秒程序会先把内容解压到系统临时目录再启动，属正常现象，稍等即可。
SmartScreen / 杀软提示Windows 可能弹出「已保护你的电脑」，点 更多信息 → 仍要运行。程序由 PyInstaller 打包、无数字签名，误报加白名单即可。
想换位置直接移动 exe 就行；配置和存档存在用户目录（见 第 7 节），不会跟着 exe 走丢。

最低要求：Windows 10/11 64 位。

2打开游戏

  • 菜单：File → Load ROM...，选 .gba / .gbc / .gb / .zip。
  • 拖放：把游戏文件直接拖进窗口。
  • 命令行 / 文件关联：mGBAx.exe "D:\ROMs\游戏.gba"；也可在资源管理器对 .gba 右键「打开方式」设为 mGBAx，以后双击即开。命令行参数会原样传给模拟器。

支持从 ZIP 内直接读取。GBA BIOS 不是必须的；如需真机 BIOS，在 Tools → Settings... → BIOS 指定。

4倍速音乐（本版核心）

入口：Tools → 模拟器增强...（菜单里唯一的中文项）。

4.1 先理解一个硬约束

游戏 4× 快进时，核心每秒会产出 4 秒的音乐内容；而声卡每秒只能播 1 秒音频。所以必须丢掉 3/4 —— 「游戏 4× + 音乐严格 1× 原速 + 音乐连续不断」三者无法同时成立，必须选一个取舍。

模式（「快进音乐」）怎么处理音高旋律节奏连续性
变调（原版行为）不丢，直接快放升 4×4×连续
不变调·连续（WSOLA）把 4 秒均匀压成 1 秒不变仍 4×连续
真正 1× 原速（NATIVE）默认原速播放真实采样，在音符间隙整段跳过冗余不变1×会跳段

最容易误解的一点：设置或日志里的「音乐速度 1×」只代表音高不变，不代表旋律是 1×。WSOLA 保住了音高，但 4 秒旋律仍被塞进 1 秒播放，听感还是"音乐在往前赶"。要严格 1× 原速，请选第三项。

4.2 四个设置项

设置项可选值说明
快进音乐3 个模式见上表。选「变调」时，下面两项会置灰不生效。
快进倍率2× / 3× / 4× / 6× / 8×
默认 4×		游戏本身的加速倍率。倍速音乐开启时以此为准，会覆盖 Emulation → Fast forward speed 菜单里的设置。
音乐速度1× / 1.5× / 2× / 3×
默认 1×		只控制音高倍率。1× = 不变调；2× 约升高一个八度（不再是"不变调"）。它不改变旋律推进速率，那由模式决定。
声道音量6 条滑杆分别调节各音频通道，拖动即时生效。

面板底部有一行状态说明；没有打开游戏时改设置会保存，但要下次打开游戏才即时生效（面板会提示）。

4.3 推荐配置

就要 1× 原速

默认即可：真正 1× 原速 + 4× + 1×。能接受偶尔跳一下。

嫌跳段太碎

把快进倍率降到 2×（丢弃量从 3/4 降到 1/2），或切回「不变调·连续」。

要完全连续

选「不变调·连续」+ 4× + 1×，接受旋律跟着快 4×。

老式磁带快进

选「变调」，音乐随游戏一起升速升调，最原始的行为。

4.4 生效条件

  1. 「快进音乐」不是「变调」；
  2. 快进倍率 ≥ 2×（1× 会让快进直接失效，旧配置会自动纠正回 4×）；
  3. 确实处于快进状态 —— 按住 Tab 或按 Shift+Tab 打开持续快进；
  4. 已经载入游戏。

5其他增强功能

同一个 Tools → 模拟器增强... 面板里还有：

  • GB 调色板：给 GB/GBC 游戏套用 14 种预设配色（含「核心默认（不覆盖）」）。
  • 光感太阳能：模拟《口袋妖怪 金/银》等卡带的光敏电阻，滑杆 -1 为关闭，0～10 调节光照强度。
  • 卡带震动：把卡带震动信号转给手柄震动。
  • 一键备份（设置+存档 → zip）：点一下选保存位置（默认 用户目录\mgba-backup.zip），把配置文件和存档一起打包，换机 / 重装前用它最省事。

8常见问题

Q：按 Tab 没反应 / 快进不加速？
检查「快进倍率」是否 ≥ 2×、是否选了「变调」、游戏是否已载入。旧版遗留的 1× 配置会自动纠正为 4×。
Q：音乐听着还是快，不是 1×？
你大概在「不变调·连续」(WSOLA) 模式 —— 它只保音高、不保节奏。切到「真正 1× 原速」即可。
Q：音乐一跳一跳的？
这是「真正 1× 原速」换取原速的代价（4× 下每约 2 秒跳掉一段）。把「快进倍率」调到 2× 会明显减轻；或改用「不变调·连续」但接受旋律 4×。
Q：改了设置没效果？
没打开游戏时只保存、不即时生效，重开游戏即可。另外本版升级过配置键名（如 audioHoldMode5、audioHoldRate2），旧值不会覆盖新默认。
Q：音乐发闷 / 断续 / 电音？
先看 %APPDATA%\mGBA\audiodiag.log 的 on 与 dropped。dropped 在「真正 1× 原速」模式下数值很大是正常的 —— 那是按计划跳段丢弃的样本，不是故障。
Q：完全没声音？
检查系统音量、Tools → Settings... → Audio 里的设备与采样率、以及增强面板的 6 条声道音量是否被拉到 0。
Q：首次启动很慢 / 被杀软删了？
首次运行要解压约 98 MB 到临时目录，属正常；无数字签名导致的误报加白名单即可。

9读诊断日志

日志每秒一行，位于 %APPDATA%\mGBA\audiodiag.log：

[AUDIOHOLD] on=1 mode=2 ratio=4.00 rate=1.00 stretch=4.02 fpsTarget=240.0 coreRate=65536 outFreq=44100 expectPitchMul=1.000 dropped=0
字段含义
on1 = 倍速音乐已接管音频；0 = 当前未在快进或功能未启用
mode0 变调 / 1 不变调·连续 / 2 真正 1× 原速
ratio快进倍率
rate音乐速度（只影响音高）
stretch实际时间拉伸比
fpsTarget目标帧率，240 ≈ 4× 原生帧率（原生约 60）
coreRate核心音频采样率；部分游戏会通过 SOUNDBIAS 切到 65536，属正常
outFreq声卡输出采样率
expectPitchMul理论音高倍率，1.000 = 不变调
droppedWSOLA 丢弃样本数；NATIVE 模式下很大是正常跳段

排查时把最近几行发出来即可定位，重点看 on / mode / expectPitchMul / dropped。

10已知限制

  • 三选二硬约束：「游戏 4× + 音乐严格 1× + 连续」不可兼得，见 4.1。
  • 「真正 1× 原速」会跳段；切点优先落在静音处并做 12 ms 淡入，但几乎没有静音的曲子仍能听出跳跃。
  • 高倍速（6× / 8×）下核心音频产出更大，音频延迟会略增。
  • 每次启动都要把约 98 MB 解压到临时目录，冷启动会比原生程序略慢。
  • 「音乐速度」的 2× / 3× 会让音高升高（约一个八度甚至更多），此时已不是"不变调"。
