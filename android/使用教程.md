# mGBAx 使用教程

> **新版功能（完整说明见《安卓版完整使用教程》）**：① **自定义 ROM 文件夹**——**设置 → ROM 文件夹** 或 **游戏库 → ROM 文件夹**，用系统文件夹选择器或手动输入路径添加自己的游戏目录；把游戏与 `.sav` / `.srm` / `.ss1` 存档放在同一个文件夹即会自动识别使用。② **一键 2 秒倒带快捷键**——虚拟按键上的「倒带2s」默认开启，点一下直接回退 2 秒，秒数可在 **设置 → 输入** 里改成 1～10 秒；原有菜单「倒带」、掌机皮肤 ⏪ 和秒数条的用法完全不变。

这是一个 Game Boy、Game Boy Color 和 Game Boy Advance 模拟器，默认横屏，也可以在 **设置** 里切换竖屏。横屏时顶部是一排可以左右滑动的按钮，中间是画面，四角和底部是虚拟按键；竖屏时界面像 NDS，上半屏是游戏画面，下半屏是按键和菜单。

支持的游戏文件是 `.gba`、`.gbc`、`.gb`。界面提示里也写了 `.zip`，当前版本不能直接打开压缩包，请先解压再选里面的游戏文件。

## 打开游戏

1. 点顶部的 **打开**。
2. 在系统文件选择器里选中游戏文件。
3. 画面中央会显示「正在读取游戏…」。读完后提示消失，游戏开始。
4. 游戏标题会出现在窗口标题上。顶部按钮右侧的绿色数字是当前倍速和帧率，例如 `1倍 60fps`。

上次成功打开的游戏会在下次启动时自动载入。读不出来时会提示「无法加载这个游戏」。

切到别的应用时游戏会暂停并静音。回到本应用后，如果之前没有手动暂停，会自动继续。

## 虚拟按键

画面上的按键和掌机对应：

| 位置 | 按键 |
| --- | --- |
| 左下 | 方向键，斜向可以同时按两个方向 |
| 右下大键 | A |
| A 左上方 | B |
| 底部中间 | SELECT、START |
| 左上、右上 | L、R |

可以多指同时按。A、B、L、R、SELECT、START 按住后手指稍微滑动也不会松开，松手才放开。

点顶部 **键位** 进入编辑：单指拖动移动按键，双指捏合缩放，也可用下方滑杆和 ＋／－ 微调（40%～300%），松手即保存，可随时调整。点 **重置** 恢复默认。

**按住 B 大约 0.2 秒会变成连发**，B 键会快速闪动，直到松手。点一下 B 仍然是普通单按。连发对触摸、键盘和手柄的 B 都有效。

## 竖屏和横屏

打开 **设置**，选 **横屏** 或 **竖屏**，切换会立刻生效，并记住选择，下次启动保持。

- 横屏：画面铺满屏幕，按键浮在画面上，菜单栏在顶部。
- 竖屏：做成 NDS 掌机的样子，上半屏是游戏画面，下半屏是按键，菜单栏移到底部（点下半屏顶部的 **菜单** 打开）。

竖屏时下半屏比横屏窄一些，方向键会自动缩小，避免和 SELECT 挤在一起。已经单独调整过的按键位置在竖屏下按比例缩放，如果不合适，可以再进一次 **键位** 微调。

## 键盘和手柄

外接键盘或手柄时使用下面的对应关系：

| 游戏按键 | 键盘 | 手柄 |
| --- | --- | --- |
| 上 | W、方向键上 | 十字键上 |
| 下 | 方向键下 | 十字键下 |
| 左 | 方向键左 | 十字键左 |
| 右 | 方向键右 | 十字键右 |
| A | X | A |
| B | Z | B |
| L | A | L1、L2 |
| R | S | R1、R2 |
| START | 回车 | Start |
| SELECT | Delete、Shift | Select |

按住 **空格**、**Tab**，或手柄 **右摇杆按下**，会临时升到至少 16 倍速，松开后回到按钮上当前的倍速；切到后台或系统弹窗打断时会自动松开。

## 暂停和倍速

- **暂停**：冻结画面和声音，按钮文字变成「继续」。再点一次恢复。
- **倍速**：点 **1倍** 展开 1～16 档，声音会跟着变速播放（磁带式快进）。倍速条里有 **倍速声音** 开关，关掉后加速时静音。打开 **倍速声音** 后还能勾选 **不变速**，让音乐保持原速、音高不变，不再像磁带那样升调。倍速时游戏产生的音频是正常速度的几倍，原生层会用 WSOLA 时间拉伸把多余的音频压缩进实时播放，所以音乐是连续、正常速度、正常音高的，不会跳段。每次启动都会回到 **1倍**，不会自动沿用上次的倍速，避免一打开游戏音调和速度就偏高。
- 右上角会显示当前倍速和帧率。

联机时请保持 **1倍**，并且不要暂停。

## 两种存档

### 游戏自己的存档

在游戏里用菜单存档（SRAM、Flash 这类电池存档）会自动保存。打开游戏后，按钮栏下面会出现一条绿字：

`ROM 存档位置：……/游戏名.sav`

点这条绿字可以把路径复制到剪贴板。每个游戏按文件名各有一份 `.sav`。

电池存档写在文件管理的 `我的手机/mGBAx/saves`。绿字按这个路径显示，例如 `我的手机/mGBAx/saves/游戏名.sav`。打开「我的手机 → mGBAx → saves」即可找到。首次使用会请求文件访问权限，允许之后才会写到这个位置。卸载应用不会删除这里的 `.sav`。从旧版本升级时，`我的手机/mGBA/saves` 里的存档会自动复制到新目录。即时存档仍在应用私有目录，卸载会删掉。

### 即时存档

即时存档不经过游戏菜单，直接记下当前画面，一共 **9 个槽位**。

1. 点 **存档**，弹出「保存到哪个槽位」。
2. 最上面一行是「当前画面（存档前）」，用来对照，不能点。
3. 下面是槽位 1 到 9。有存档的会显示缩略图和保存时间，例如 `10月12日 02:10`；没有的显示「空」。
4. 点一个槽位即可写入。已经有内容的槽位会被覆盖。
5. 成功后提示「已保存即时存档 N」。

读取时点 **读档**，在「读取哪个槽位」里点有画面的那一行。空槽位会提示「没有即时存档 N」。

**槽位** 按钮用来查看和切换当前槽位，从 1 轮到 9。已经有即时存档的槽位会显示圆点，例如 `槽位 3 ●`。真正保存和读取以「存档」「读档」弹出的列表为准。

## 复位

点 **复位** 会立刻重新启动当前游戏，并提示「已复位」。电池存档还在，即时存档也不会被删。

## BIOS

多数游戏不用 BIOS 也能运行。需要官方开机程序的游戏，可以自己导入：

1. 点 **BIOS**，选择 BIOS 文件。
2. 应用按文件名和大小自动归类：
   - 文件名含 `gba`，或大小为 16384 字节：GBA BIOS
   - 文件名含 `gbc` 或 `cgb`，或大小为 2304 字节：GBC BIOS
   - 文件名含 `sgb`：SGB BIOS
   - 其他：GB BIOS
3. 成功后提示「已导入 ……，重新打开游戏后生效」，并自动重新打开上次的游戏。

导入失败会提示「BIOS 导入失败」。开机的 Nintendo 标志动画会被跳过，BIOS 仍会在游戏运行时使用。

## 画质

点 **画质**。改动会马上生效，并在下次打开时保留。

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 帧间混合 | 关 | 把相邻帧混在一起，减轻部分游戏的闪烁 |
| 双线性过滤 | 开 | 放大后边缘更柔和。关掉则是清晰的像素块 |
| 锁定宽高比 | 开 | 保持游戏原始比例，两侧或上下留黑边 |
| 整数缩放 | 关 | 只按整数倍放大，像素更整齐，画面可能更小 |
| 扫描线 | 关 | 加上横向扫描线 |
| 跳帧 | 0 | 0 到 5。数值越大越容易掉画面，用来换流畅度 |
| 亮度 | 100% | 可在 50% 到 150% 之间调节 |

## 联机

点 **联机**。这是 GBA 联机线，两边必须打开 **同一个游戏**，保持 **1倍**，并且 **不要暂停**。创建房间或局域网主机的一方是 **1P**，加入的一方是 **2P**。

对话框里的说明、上次填写的地址和端口都会留着。打完后点 **断开** 结束连接。

### 联机大厅

对话框最下面一段是 **联机大厅**，用于和对方模拟器的 Wi-Fi 联机互通（协议与其他模拟器的「本地联机 → Wi-Fi」一致，端口默认 `6374`）。

1. 两边都打开 **同一个游戏文件**（文件名可以不同，但必须是同一个 ROM）。
2. 一边点 **大厅创建**，状态变成「联机大厅等待连接」，这台设备是 **1P**。
3. 另一边在 **对方 IP** 填创房一方的 IP，端口保持 `6374`，点 **大厅加入**，这台设备是 **2P**。
4. 接通后两边每 5 帧交换一次按键：对方在这台设备上操控的是 **2P 的按键**（与本地输入合并生效）。
5. 对方按游戏里的 **复位** 时，本机游戏也会跟着复位；本机复位也会通知对方。

联机大厅的说明：

- 连接建立时两边会交换游戏指纹（ROM 的 MD5）。两边 ROM 不一致会提示「两边的游戏不一致」，此时联机可能无法正常同步。
- 接通时会交换一次即时存档。本机 **不读取** 对方的存档（格式不通），游戏继续用本机自己的进度；对方发来的存档仅供参考。请先用游戏内的电池存档把两边进度带到同一位置再联机。
- 不同模拟器核心无法做到逐周期一致，需要联机线实时对话的对战 / 交换在两边进度差异较大时可能不同步。保持两边从相同的存档进度出发可以显著改善。

### 同一 Wi-Fi（局域网）

1. 1P 确认端口（默认 `8765`），点 **局域网创建**。
2. 状态变成「等待连接」，并显示本机地址，例如 `192.168.1.8:8765`。
3. 2P 在「对方 IP」里填写 1P 的 IP，端口保持一致，点 **局域网加入**。
4. 接通后 1P 看到「已连接，你是 1P」，2P 看到「已连接，你是 2P」。

两台设备要在同一个局域网，路由器不要隔离设备。端口无效会提示「端口无效」；IP 不对会提示「IP 地址无效」或「连不上对方」。对方中途退出时，1P 会继续等待，可以让对方再加入。

### 互联网（中继）

两边填写 **同一个中继地址**，格式是 `IP:端口`，例如 `1.2.3.4:8766`。不写端口时默认 `8766`。

1. 两边都打开同一个游戏。
2. 1P 填写中继地址，点 **远程创建**。
3. 房间号会自动出现，并复制到剪贴板。把它发给对方。房间号是 6 位，不含容易看混的 `I`、`O`、`0`、`1`。
4. 2P 填写同一个中继地址和这个房间号，点 **远程加入**。
5. 接通后 1P 是「已接通中继，你是 1P」，2P 是「已接通中继，你是 2P」。

中继地址留空再点 **远程创建** 时，由这台手机自己当中继，默认从 `8766` 起找可用端口。只有对方能够直接访问这台手机的 IP 时才用这种方式。加入的一方不能留空，必须填写创建方提示里的中继地址。

常见提示：

| 提示 | 含义 |
| --- | --- |
| 先填写房间号 | 远程加入时房间号是空的 |
| 加入时要填写对方的中继地址 | 加入方把中继留空了 |
| 连不上中继 | 地址、端口或网络不通 |
| 没有这个房间 | 房间号错误，或创建方已经断开 |
| 房间已满 | 这个房间已经有两个人 |
| 等待对方超时 | 创建后约 15 分钟内没有人加入 |
| 对方已断开 | 对端退出或网络中断 |
| 请先打开一个游戏再联机 | 联机大厅需要先加载游戏 |
| 两边的游戏不一致 | 双方 ROM 的 MD5 不同，联机可能无法同步 |

## 常见问题

**打开后黑屏或提示无法加载。** 确认文件是未压缩的 `.gba`、`.gbc` 或 `.gb`。`.zip` 需要先解压。

**没有声音。** 先看系统媒体音量。倍速时如果关掉了 **倍速声音** 会静音，打开后默认声音随倍速变速播放（磁带式）。若勾选了 **不变速**，音乐则保持原速、音高不变。按住空格、Tab、右摇杆是临时 16 倍速，同样受该开关控制。回到 1 倍并松开快进键后恢复正常。

**音乐忽快忽慢、音调乱变。** 卡顿、切到后台或读盘造成的一次性掉帧不会改变音调；只有设备长期跑不满帧率时，音乐才会跟着游戏一起放慢（磁带式），这是正常现象。

**游戏里的存档不见了。** 电池存档跟游戏文件名绑定。文件名变了，就会变成另一份存档。文件在文件管理的「我的手机/mGBAx/saves」，不在应用私有目录里。旧版本（mGBA 目录）的存档会自动复制过来。

**即时存档读不回来。** 槽位是按当前这个游戏分开的。换了一个游戏，看到的是那个游戏自己的 9 个槽位。

**联机对不上。** 两边打开同一个 ROM，都用 1 倍速，都不要暂停。局域网先看 IP 和端口；互联网两边的中继地址必须一致，房间号用创建方刚生成的那一个。
