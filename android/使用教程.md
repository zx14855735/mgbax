# mGBAx 安卓版 · 快速上手

完整说明（联机、调试、滤镜、存档细节）见仓库根目录 **[`安卓版完整使用教程.md`](../安卓版完整使用教程.md)**。这里只讲最快能玩起来的几件事。

## 1. 跑起来

1. 点菜单栏 **打开** → 选 `.gba` / `.gbc` / `.gb` / `.zip`。
2. 首次会申请「所有文件访问」，**必须允许**，否则存不进档。
3. 下次启动自动继续上次的游戏。

## 2. 六个最常用的按钮

| 按钮 | 什么时候用 |
|---|---|
| **暂停** | 想停一下 |
| **倍速** | 刷级：`2x` / `4x`；慢放看细节：`0.5x` |
| **存档 / 读档** | 随时存 checkpoint（9 个手动槽 + 1 个自动槽） |
| **撤销** | 读错档、存错槽，一键退回去 |
| **倒带** | 手滑了回到几秒前（屏幕上还有个「倒带2s」快捷键） |
| **联机** | 和异地朋友交换 / 对战 |

## 3. 存档放哪

- 电池存档（游戏自己的存档）：`我的手机/mGBAx/saves`
- 即时存档：和 ROM 同名同目录，如 `游戏名.ss1`
- 菜单栏下方**绿字**就是当前实际路径，点一下可复制

想把游戏和存档放一起：把 `游戏.gba`、`游戏.sav`、`游戏.ss1` 丢进同一个文件夹，加载时会自动认（游戏库里会标 **[同目录有存档]**）。

## 4. 联机三条铁律

1. 两边**同一个 ROM**（内容一致）
2. 两边**不能共用同一份 `.sav`**
3. 两边**倍速必须一样**（只有 `0.5x/1x/2x/4x` 会同步）

异地用 **联机 → 云端创建 / 云端加入**（gboy.top，要注册，房号给对面）；同一个 WiFi 想 3–4 人用 **联机 → 局域网**。

## 5. 卡了先试这些

| 现象 | 先做什么 |
|---|---|
| 黑屏 / 打不开 | 每游戏设置里换存档类型；导入 BIOS |
| 没声音 | 音量、6 路通道音量、低延迟音频开关 |
| 联机一顿一顿 | 两边倍速不同档 |
| 画面糊 | 画质 → 开「整数缩放」+ 选 HQ2x / 4xBR |
| 要反馈问题 | **设置 → 导出诊断包**，比截图有用 |
