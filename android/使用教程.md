# mGBAx 使用教程

> **新版功能（完整说明见《安卓版完整使用教程》）**：① **自定义 ROM 文件夹**——**设置 → ROM 文件夹** 或 **游戏库 → ROM 文件夹**，用系统文件夹选择器或手动输入路径添加自己的游戏目录；把游戏与 `.sav` / `.srm` / `.ss1` 存档放在同一个文件夹即会自动识别使用。② **一键 2 秒倒带快捷键**——虚拟按键上的「倒带2s」默认开启，点一下直接回退 2 秒，秒数可在 **设置 → 输入** 里改成 1～10 秒；原有菜单「倒带」、掌机皮肤 ⏪ 和秒数条的用法完全不变。

这一轮加的东西不少，但入口都在原来那条菜单栏上，进游戏后左右滑动就能看到：

| **帧进按钮** | 菜单栏 **帧进**（在「暂停」右边） | 暂停后一帧一帧走，长按可以**倒退一帧** |

| **按键宏录制 / 回放** | **设置 → 输入 → 按键宏录制/回放** | 录一段操作，按帧回放 |
| **新调试工具** | 菜单栏 **调试** | 新增内存变化监视、地图查看器、图块查看器、I/O 寄存器、帧检查器 |

下面按「怎么用」讲。功能位置都写在每节开头。

---

这是一个 Game Boy、Game Boy Color 和 Game Boy Advance 模拟器，默认横屏，也可以在 **设置** 里切换竖屏。横屏时顶部是一排可以左右滑动的按钮，中间是画面，四角和底部是虚拟按键；竖屏时界面像 NDS，上半屏是游戏画面，下半屏是按键和菜单。

支持的游戏文件是 `.gba`、`.gbc`、`.gb`，也可以直接选 `.zip`（会自动取出压缩包里的第一个游戏文件，不用手动解压）。

## 打开游戏

1. 点顶部的 **打开**。
2. 在系统文件选择器里选中游戏文件。
3. 画面中央会显示「正在读取游戏…」。读完后提示消失，游戏开始。
4. 游戏标题会出现在窗口标题上。顶部按钮右侧的绿色数字是当前倍速和帧率，例如 `1倍 60fps`。

上次成功打开的游戏会在下次启动时自动载入。读不出来时会提示「无法加载这个游戏」。

切到别的应用时游戏会暂停并静音。回到本应用后，如果之前没有手动暂停，会自动继续。

## 虚拟按键

画面上的按键和掌机对应：

| 位置 | 按键 |
| --- | --- |
| 左下 | 方向键，斜向可以同时按两个方向 |
| 右下大键 | A |
| A 左上方 | B |
| 底部中间 | SELECT、START |
| 左上、右上 | L、R |

可以多指同时按。A、B、L、R、SELECT、START 按住后手指稍微滑动也不会松开，松手才放开。

点顶部 **键位** 进入编辑：单指拖动移动按键，双指捏合缩放，也可用下方滑杆和 ＋／－ 微调（40%～300%），松手即保存，可随时调整。点 **重置** 恢复默认。

**按住 B 大约 0.2 秒会变成连发**，B 键会快速闪动，直到松手。点一下 B 仍然是普通单按。连发对触摸、键盘和手柄的 B 都有效。

## 竖屏和横屏

打开 **设置**，选 **横屏** 或 **竖屏**，切换会立刻生效，并记住选择，下次启动保持。

- 横屏：画面铺满屏幕，按键浮在画面上，菜单栏在顶部。
- 竖屏：做成 NDS 掌机的样子，上半屏是游戏画面，下半屏是按键，菜单栏移到底部（点下半屏顶部的 **菜单** 打开）。

竖屏时下半屏比横屏窄一些，方向键会自动缩小，避免和 SELECT 挤在一起。已经单独调整过的按键位置在竖屏下按比例缩放，如果不合适，可以再进一次 **键位** 微调。

## 键盘和手柄

外接键盘或手柄时使用下面的对应关系：

| 游戏按键 | 键盘 | 手柄 |
| --- | --- | --- |
| 上 | W、方向键上 | 十字键上 |
| 下 | 方向键下 | 十字键下 |
| 左 | 方向键左 | 十字键左 |
| 右 | 方向键右 | 十字键右 |
| A | X | A |
| B | Z | B |
| L | A | L1、L2 |
| R | S | R1、R2 |
| START | 回车 | Start |
| SELECT | Delete、Shift | Select |

按住 **空格**、**Tab**，或手柄 **右摇杆按下**，会临时升到至少 16 倍速，松开后回到按钮上当前的倍速；切到后台或系统弹窗打断时会自动松开。

## 暂停和倍速

- **暂停**：冻结画面和声音，按钮文字变成「继续」。再点一次恢复。
- **帧进**：暂停状态下点菜单栏的 **帧进**，只往前走一帧。排查花屏、卡顿、时序问题时很有用。
  - 在 **设置 → 输入** 里打开 **「逐帧倒带」** 后，**长按「帧进」会后退一帧**（内部用最近 4 份快照回放）。刚开局没有快照时会提示「没有可回退的快照」。
  - **联机中不能逐帧倒带**，会提示「联机中不能逐帧倒带（会把对端进度甩开）」。
- **倍速**：点 **1倍** 展开倍速条，档位是 **`0.25 / 0.5 / 1 / 2 / 4 / 8 / 16`**，最右边 **自定义** 可以输入 `0.05～16` 之间的小数（支持慢动作）。声音会跟着变速播放（磁带式快进）。倍速条里有 **倍速声音** 开关，关掉后加速时静音。打开 **倍速声音** 后还能勾选 **不变速**，让音乐保持原速、音高不变，不再像磁带那样升调。倍速时游戏产生的音频是正常速度的几倍，原生层会用 WSOLA 时间拉伸把多余的音频压缩进实时播放，所以音乐是连续、正常速度、正常音高的，不会跳段。每次启动都会回到 **1倍**，不会自动沿用上次的倍速，避免一打开游戏音调和速度就偏高。
- 右上角会显示当前倍速和帧率。

### 联机时用「倍速」同步

联机中切到 **0.5x / 1x / 2x / 4x** 这四档，会把倍速发给对端，对端跟着一起快、一起慢（PC 端对应 `Tools → Speed`）。所以联机不想快进时两边都停在 **1倍** 就行。

> **注意**：只有这四个官方档位会同步。用 **自定义** 输入的其它倍速（比如 1.5x、0.25x、8x）只在**本机**生效，对端收不到。
>
> **注意：两端必须选同一个倍速。** 一边 1x 一边 4x 会互相拉扯，画面一顿一顿、联机对话错位。这是联机最常见的「卡」的原因，不是网络问题。

## 两种存档

### 游戏自己的存档

在游戏里用菜单存档（SRAM、Flash 这类电池存档）会自动保存。打开游戏后，按钮栏下面会出现一条绿字：

`ROM 存档位置：……/游戏名.sav`

点这条绿字可以把路径复制到剪贴板。每个游戏按文件名各有一份 `.sav`。

电池存档写在文件管理的 `我的手机/mGBAx/saves`。绿字按这个路径显示，例如 `我的手机/mGBAx/saves/游戏名.sav`。打开「我的手机 → mGBAx → saves」即可找到。首次使用会请求文件访问权限，允许之后才会写到这个位置。卸载应用不会删除这里的 `.sav`。从旧版本升级时，`我的手机/mGBA/saves` 里的存档会自动复制到新目录。即时存档仍在应用私有目录，卸载会删掉。

**导出 / 导入电池存档**：**设置 → 存档 → 电池存档导出 / 导入**。

- **导出当前电池存档(.sav)**：选个保存位置即可，适合发给别人或换机前留底。
- **从文件导入电池存档(.sav / .srm)**：选一份存档覆盖当前游戏的 `.sav`，导入后自动重新载入游戏。接收别人存档、或者从别的模拟器迁移时用。
- 还没在游戏里存过档时，会提示「还没有电池存档」。

### 即时存档

即时存档不经过游戏菜单，直接记下当前画面，一共 **10 个位置**：**槽位 1～9**（手动）+ **槽位 0**（自动存档专用，不在列表里显示）。

1. 点 **存档**，弹出「保存到哪个槽位」。
2. 最上面一行是「当前画面（存档前）」，用来对照，不能点。
3. 下面是槽位 1 到 9。有存档的会显示缩略图和保存时间，例如 `10月12日 02:10`；没有的显示「空」。
4. 点一个槽位即可写入。已经有内容的槽位会被覆盖（旧内容会备份成 `.bak`，见下面的「撤销」）。
5. 成功后提示「已保存即时存档 N」。

读取时点 **读档**，在「读取哪个槽位」里点有画面的那一行。空槽位会提示「没有即时存档 N」。

**槽位** 按钮用来查看和切换当前槽位，从 1 轮到 9。已经有即时存档的槽位会显示圆点，例如 `槽位 3 ●`。真正保存和读取以「存档」「读档」弹出的列表为准。

槽位 0 是给 **进入游戏时自动读档 / 退出时自动存档** 用的（在 **设置 → 存档** 里开关），你手动选不到它，它也不会把 1～9 号的进度顶掉。

### 撤销（读错了能退回来）

菜单栏 **撤销**（在「读档」右边）：

- **撤销上一次读档**：读档前会先把当时的进度缓存在内存里，读错档点一下就能回到读档前。**只在本次运行内有效**，杀掉应用就没了。
- **撤销上一次存档**：存档前会把该槽位的旧内容备份成 `.ssN.bak`，点一下还原。这个备份**重启后仍然有效**。
- 没有可撤销的内容时会明确提示（例如「没有可撤销的存档（该槽位上次是空的）」）。

## 录像与截图

- **录像（MP4）**：点菜单栏 **录像** 开始，按钮变成 **停止录像**，再点一次结束。文件是 **H.264 + AAC** 的 MP4，存到 **`Movies/mGBAx`**，结束时提示文件名和时长。如果点得太快、没录出有效文件，会提示「录像过短，已丢弃」。
- **截图**：点菜单栏 **截图**，存到 **`Pictures/mGBAx`**。格式在 **设置 → 输入 → 截图格式** 里选 **PNG / JPG**。
- **双击屏幕截图**：**设置 → 输入 → 双击屏幕截图**，游戏中双击画面即存。
- **GIF**：点菜单栏 **GIF** 开始，再点 **停止GIF** 结束；也可以在 **设置 → 高级 → GIF 浮球** 打开画面上的悬浮球，随时开关。

## 复位

点 **复位** 会立刻重新启动当前游戏，并提示「已复位」。电池存档还在，即时存档也不会被删。

## BIOS

多数游戏不用 BIOS 也能运行。需要官方开机程序的游戏，可以自己导入：

1. 点 **BIOS**，选择 BIOS 文件。
2. 应用按文件名和大小自动归类：
   - 文件名含 `gba`，或大小为 16384 字节：GBA BIOS
   - 文件名含 `gbc` 或 `cgb`，或大小为 2304 字节：GBC BIOS
   - 文件名含 `sgb`：SGB BIOS
   - 其他：GB BIOS
3. 成功后提示「已导入 ……，重新打开游戏后生效」，并自动重新打开上次的游戏。

导入失败会提示「BIOS 导入失败」。开机的 Nintendo 标志动画会被跳过，BIOS 仍会在游戏运行时使用。

## 画质

点 **画质**。改动会马上生效，并在下次打开时保留。

**画面滤镜**：点「画面滤镜」选一项，共 **12 项**（「关闭」+ 11 种效果），另有 **外部渲染器**。

| 滤镜 | 效果 |
| --- | --- |
| 关闭 | 原始高清放大（默认） |
| GBA 色彩 | 模拟 GBA 屏幕偏暗、偏绿的真实发色 |
| 灰度 | 黑白 |
| HQ2x / HQ4x | 平滑像素斜边与圆角，4x 更细腻 |
| 2xBR / 4xBR | xBR 系平滑，线条更利落 |
| 残影 | 模拟慢响应 LCD 的拖影（用 7 帧历史混合） |
| 点阵 | 模拟老掌机的像素格子 |
| LCD3x | 模拟 LCD 三色子像素 |
| 扫描线（平滑） | 柔和的逐行变暗 |
| 锐利插值 | 非整数倍缩放时像素依然干净 |
| 外部渲染器 | 装第三方 `.glsl` 单通道着色器，见下 |

**其他画面选项**：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 帧间混合 | 关 | 把相邻帧混在一起，减轻部分游戏的闪烁 |
| 双线性过滤 | 开 | 放大后边缘更柔和。关掉则是清晰的像素块 |
| 锁定宽高比 | 开 | 保持游戏原始比例，两侧或上下留黑边 |
| 整数缩放 | 关 | 只按整数倍放大，像素更整齐，画面可能更小 |
| 扫描线 | 关 | 加上横向扫描线 |
| 跳帧 | 自动 | 0 到 5，或选 **自动跳帧**：跟不上时自动跳、跟得上恢复全帧 |
| 亮度 | 100% | 可在 50% 到 150% 之间调节 |
| 对比度 | 100% | 同上 |
| 图层显隐 | 全部显示 | 单独关 BG0～BG3 / OBJ（精灵） |
| 画面场景 | — | 调水平/垂直位置与缩放，可「恢复居中」 |

**图层显隐**：排查花屏、只留背景看地图时用。它是每帧强制写 DISPCNT 的使能位实现的，个别游戏会在 VBlank 改写 DISPCNT，运行时可能闪一下；想稳定看单帧，先 **暂停** 再点 **帧进**。

**外部渲染器**：点 **安装渲染器（.glsl）** 导入第三方单通道 GLSL ES 片段着色器。可用变量 `uTex`（游戏画面）、`vTexCoord`、`uTexSize`、`uOutSize`、`uBrightness`；常见 RetroArch 命名（`TEXTURE` / `TextureSize` / `OutputSize` / `vTexCoord` / `COMPAT_TEXTURE`）会自动适配。装坏了选回「无」即可。

滤镜配合「整数缩放」效果最好；亮度、对比度对滤镜同样生效。

## 联机

点 **联机**。这是 GBA 联机线：两边必须打开 **同一个游戏**（文件名可以不同，但必须是同一份 ROM），并且 **不要暂停**。创建/开房的一方是 **1P**，加入的一方是 **2P**。

对话框里现在有两段：上面是 **云端房间（gboy.top）**，下面是 **局域网多人（3/4 人）**。上次填的邮箱、房号、IP 都会留着。

### 先记住三条

1. **两边要打开同一个 ROM。** 不同汉化版、不同 dump 都算不同 ROM。
2. **两边不要用同一份电池存档。** 把同一个 `.sav` 拷到两台机器上，游戏里的玩家 ID 一样，联机交换会出问题。各自从头开始，或各自用不同的存档。
3. **两边倍速必须一致。** 联机中用 `0.5x / 1x / 2x / 4x` 会同步；自定义倍速不同步，容易拉扯（见「暂停和倍速」）。

### 云端房间（gboy.top，异地也能连）

1. 两边先打开同一个游戏。
2. 点 **联机**，在上半部分填 **邮箱**：
   - **新账号**：点 **获取验证码**（同一邮箱 5 分钟一次）→ 去邮箱收码 → 填 **验证码** 和 **密码** → 点 **云端创建 / 云端加入** 时会自动注册并登录。
   - **老账号**：直接在 **密码** 框填原密码，点创建 / 加入即可，**不会再发邮件**。首次登录后账号会记住。
3. **创建方**：房间号留空，点 **云端创建**。状态里会出现房号，把它发给对方（你是 1P）。
4. **加入方**：在 **房间号** 填对方给的号，点 **云端加入**（你是 2P）。
5. 状态栏会先显示「房间已创建，房号 …」，接着显示当前走的通道（中继 / 服务器隧道 / 直连加速已启用）。双方就绪后进游戏里的联机房间即可。

**连上以后会发生什么：**

- **分开控制**：各自玩各自的画面。对端按键**不会**灌进你的游戏；游戏内的交换 / 对战走模拟器的联机线，和插对战线一个语义。
- **连上会同步一次存档**：两端各自把当前即时存档发给对方，对方把它灌进「代表你」的隐藏核，让双方从同一幕开始。**你屏幕上的进度不会被对方的存档覆盖**，可以放心。
- **复位联动**：点 **复位**，对端所有核一起复位；对端点复位，你这边也会复位。
- **断线**：云端房间**不会自动重连**。先点 **重新连接中继**（需先有房间，不重建房间，只重解析节点并重连）；还不行就断开重新建房 / 加入。
- **TCP / 蓝牙直连会自动重连**：客户端模式断线后每 **2 秒**重试一次，最多 **50 秒**；服务端只等对方连入。

**三条通道自动选，不用你管：**

| 通道 | 说明 |
| --- | --- |
| UDP 中继 | 大厅分配的公共节点，延迟最低 |
| 服务器隧道 | 中继节点不通时自动切换，数据走大厅的 WebSocket（出站 TCP，不受 NAT/UDP 限制），状态会显示「没有可用的中继地址，直接使用服务器隧道模式」 |
| **直连 P2P** | 隧道握手后顺手打洞。成功时显示「直连加速已启用（P2P 对端地址，RTT x ms）」；打不通就继续用隧道，不报错；直连中途断了会自动回落隧道，联机不中断 |

协议和 PC 版完全一致，所以 **手机 ↔ PC 也能互连**（PC 用 `File → 联机大厅…`）。

**常见提示**：

| 提示 | 含义 |
| --- | --- |
| 请先打开一个游戏再联机 | 先载入 ROM |
| 请填写有效的邮箱地址 | 邮箱格式不对 |
| 已注册账号请直接在密码框填原密码；只有新账号才需要先获取验证码 | 老账号不用验证码 |
| 加入时请填写房间号 | 加入方房号是空的 |
| 连不上 / 等待对方超时 | 房号不对，或对方已离开 |
| 两边的游戏不一致 | ROM 不同，联机可能无法同步 |

### 局域网多人（3/4 人，同 WiFi）

对话框下半部分。适合 4 个人在同一路由器下打《宝可梦》四人对战。

1. 房主在 **人数** 填 `3` 或 `4`，点 **开房（3/4 人）**。
2. 其他人填 **房主 IP**（例如 `192.168.1.10`），人数填**一样**的值，点 **加入（3/4 人）**。
3. 默认每台设备只跑自己的核，设备之间由总线互连；**勾选「本机多核锁步」** 后改为每台设备本机跑全套核、SIO 走进程内锁步，网络只传按键（实验性，状态会记住）。

> **注意**：所有人人数必须填一致；路由器开了「AP 隔离」会连不上。

### 蓝牙直连 / TCP 直连

这两个通道**目前没有界面**，只提供 ADB 广播入口（给脚本和自动化用，普通玩家用云端房间就够了）：

```bash
# 蓝牙：不带 mac = 本机当服务端等待；带 mac = 连过去
adb shell am broadcast -a io.mgba.android.action.BT --es mac AA:BB:CC:DD:EE:FF
# TCP：peer 留空 = 本机监听，填 host:port = 连过去
adb shell am broadcast -a io.mgba.android.action.TCP --es peer 192.168.1.8:19876
```

Android 12 及以上第一次用蓝牙会弹 `BLUETOOTH_CONNECT` 权限，允许后才会真的连接。**iOS 端不提供 RFCOMM 蓝牙**，手机和 PC 之间请用云端房间或 TCP。

### 用 ADB 驱动联机（调试 / 自动化）

模拟器里的按钮在部分设备上被 SurfaceView 挡住点不到，所以留了一组广播入口。**需要开 USB 调试、在电脑上用 adb 发送**，普通玩家可以跳过这一节。

| 广播 action | 作用 | 常用参数 |
| --- | --- | --- |
| `io.mgba.android.action.ROM` | 无文件选择器直接开 ROM | `--es path /sdcard/rom.gba` |
| `io.mgba.android.action.CLOUD` | 直接进 gboy.top 房间 | `--es user U --es pass P --es room R`（room 留空=建房） |
| `io.mgba.android.action.SIGNAL` | 只跑信令自检并打印每一步 | `--es mode host\|join` |
| `io.mgba.android.action.NO_RELAY` | 强制走服务器隧道，跳过公共中继 | 无（必须在 CLOUD 之前发） |
| `io.mgba.android.action.BT` / `TCP` | 蓝牙 / TCP 直连 | 见上 |
| `io.mgba.android.action.SPEED` | 本机切联机倍速 | `--ei value 1`（1x）/ `-1`（0.5x）/ `2` / `4` |
| `io.mgba.android.action.STATE` | 无按钮存档 / 读档 | `--es cmd save\|load --ei slot 3` |
| `io.mgba.android.action.KEYS` | 直接设置按住的按键掩码（保持按下） | `--ei mask 3` |
| `io.mgba.android.action.SCREENSHOT` | 截当前的 GBA 帧 | 无 |
| `io.mgba.android.action.REMOTE_KEYS` | 开 My Boy! 式「一人控两端」 | `--ez on true` |
| `io.mgba.android.action.GBOY_LOCAL_LINK` | 无头启动本地联机线 | `--ez host true --ei tcp 19876 --es rom /sdcard/rom.gba`；`--ez dialog true` 只打开联机对话框；`--ez stop true` 断开 |
| `io.mgba.android.action.GBOY_BUSGAME` | 联机回归测试脚本 | `--ez enable true --ei menu_at 1500 --ei mode_downs 2` |

`GBOY_LOCAL_LINK` 还能开 3/4 人：`--ei players 4 --ez ncore true`（本机多核 + 总线），再加 `--ez use_lockstep true` 改用进程内锁步 SIO（会自动打开 `ncore`）。

**联机排查日志**：GBA 联机时每 60 次轮询会打一行 `PEEK st=... link[m=.. id=.. pc=.. sq=.. rq=.. pos=x,y map=g.n ...]`，用 `adb logcat` 看。它能告诉你双方在不在同一张图的同一格、发送/接收队列有没有堵。**注意这行日志的地址是按 pokeemerald 系（绿宝石）内存布局写死的**，别的游戏里数值没有意义。

## 工具：快捷方式、宏、诊断包

这些都在 **设置** 里，不在菜单栏上。

### 创建桌面快捷方式

**设置 → 创建桌面快捷方式**：给当前这款 ROM 在桌面生成一个图标，以后点图标直接进游戏，不用先开应用再翻游戏库。Android 7.1 以下不支持，会提示「当前系统不支持桌面快捷方式」。

### 按键宏录制 / 回放

**设置 → 输入 → 按键宏录制/回放**：

1. 点 **开始录制**，然后正常操作（录制期间会统计帧数）。
2. 回到面板点 **停止录制并保存**，提示「宏已保存（N 帧）」。
3. 点 **回放** 按帧重放；**删除已保存的宏** 清掉。

宏**只对这一款 ROM 生效**，回放时请保持与录制时相同的倍速（默认 1x），否则节奏会对不上。

### 键盘 / 手柄映射

**设置 → 输入 → 键盘映射…**：给十字键、A/B/L/R、START/SELECT 逐个绑定实体按键或蓝牙手柄键。TAB / 空格 / 右摇杆按下已经被快进占用，会提示换一个键。**只影响实体按键**，屏幕上的虚拟按键不受影响。可单项恢复默认，也可全部恢复。

### ROM 信息

**设置 → ROM 信息**：显示卡带头（标题、游戏代码、厂商、版本、头校验）和运行状态（文件大小、CRC32、存档类型、电池存档实际路径）。存档类型选错时先来这里看。

### 导出诊断包

**设置 → 导出诊断包**：生成一个 zip，里面有 `device.txt`（机型、系统、屏幕、核心分辨率、音频采样率、存档权限）、`settings.json`（全部设置项）、`saves.txt`（电池存档与 0～9 号即时存档的大小/时间）、`roms.txt`（最近 ROM、CRC32、ROM 文件夹、收藏）、`runtime.txt`（内存、线程、当前倍速、联机状态）。反馈问题时把它发给开发者，比截图有用得多。

### 联机调试时的运行日志

应用内没有日志查看器，用 ADB 看：

```bash
adb logcat -s GBoyLink GBoySocketLink GBoyCloudLink mGBA
```

联机的握手、通道切换、倍速收发都会打在这里。

## 常见问题

**打开后黑屏或提示无法加载。** 确认文件是 `.gba`、`.gbc` 或 `.gb`；`.zip` 也可以直接选，但里面要有一个能识别的游戏文件。文件损坏或下载不完整时换一份再试。

**没有声音。** 先看系统媒体音量。倍速时如果关掉了 **倍速声音** 会静音，打开后默认声音随倍速变速播放（磁带式）。若勾选了 **不变速**，音乐则保持原速、音高不变。按住空格、Tab、右摇杆是临时 16 倍速，同样受该开关控制。回到 1 倍并松开快进键后恢复正常。

**音乐忽快忽慢、音调乱变。** 卡顿、切到后台或读盘造成的一次性掉帧不会改变音调；只有设备长期跑不满帧率时，音乐才会跟着游戏一起放慢（磁带式），这是正常现象。

**游戏里的存档不见了。** 电池存档跟游戏文件名绑定。文件名变了，就会变成另一份存档。文件在文件管理的「我的手机/mGBAx/saves」，不在应用私有目录里。旧版本（mGBA 目录）的存档会自动复制过来。

**即时存档读不回来。** 槽位是按当前这个游戏分开的。换了一个游戏，看到的是那个游戏自己的 9 个手动槽（另有 1 个自动槽不显示）。

**读错档 / 存错档了。** 点菜单栏 **撤销**：撤销读档只在本次运行有效（缓存在内存里），撤销存档靠 `.ssN.bak`，重启后也能还原。

**联机对不上 / 画面一顿一顿。** 先看两边倍速是不是同一档：只有 `0.5x/1x/2x/4x` 会同步，自定义倍速（1.5x 之类）不会，两端不同步就会互相拉扯。再看是不是同一个 ROM、是不是各用各的存档。云端房间连不上时，点 **重新连接中继**，或断开重来一次。

**录像按钮没反应 / 录像文件找不到。** 录像需要先载入 ROM；文件在 `Movies/mGBAx`。点得太快没录出内容时会提示「录像过短，已丢弃」。如果系统相册看不到，用文件管理器进 `Movies/mGBAx` 找。

**GIF 录不了。** 先用菜单 **GIF** 试一次；开了 **设置 → 高级 → GIF 浮球** 但看不到小球时，关掉再开一次。

## 未写进教程的功能及原因

| 功能 | 为什么没写 |
|---|---|
| `GBOY_BUSGAME` 的 `menu_at` / `mode_downs` 具体取值 | 是给联机回归脚本用的帧级编排参数，取值和具体 ROM 强绑定，写出来只会误导普通玩家 |
| `SIGNAL` 广播的 `--es probes a,b,c` | 用于探测房间协议各步骤，属于抓包级调试，普通玩家用不到 |
| 内部 `MGBA_LINK_PEEK` 编译开关 | 默认就编译进去，玩家没有可操作的东西；只把日志格式写进了「联机排查日志」 |
| 云端的 `--es ws` / `--es api` 端点重定向 | 用于连 mock 大厅做自动化测试，正式版用户改了只会连不上 |
