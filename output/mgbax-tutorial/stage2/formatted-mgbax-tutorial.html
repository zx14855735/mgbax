mGBAx 安卓版完整使用教程

  mGBAx 是 mGBA 模拟器在 Android 上的移植版本（应用名 mGBAx），可运行 Game Boy Advance（GBA）、Game Boy Color（GBC）、Game Boy（GB） 游戏，最大支持 64MB 扩容 ROM，并可直接从 ZIP 内加载。本教程覆盖菜单栏里每一项功能的具体用法。

  • 系统要求：Android 7.0 及以上。
  • 存档位置：游戏自己的电池存档默认保存在 我的手机/mGBAx/saves；如果 ROM 同目录里已经有同名存档，则自动改用同目录那一份（见 11.2）。打开游戏后菜单栏下方绿色文字会显示当前 ROM 的实际存档路径。

  新版新增：① 自定义 ROM 文件夹——游戏文件和存档放在同一个文件夹就能自动识别，见 11.1 / 11.2；② 一键 2 秒倒带快捷键——点一下直接回退 2 秒，见 9.1。原有倒带条、菜单「倒带」与掌机皮肤 ⏪ 的用法完全不变。

1. 界面总览

打开任意游戏后，顶部会浮出一条可横向滚动的菜单栏，右侧绿色文字显示当前倍速 / 帧率（FPS）。菜单栏按钮从左到右为：

2. 打开游戏

  • 方式一（推荐）：点菜单栏 打开，用系统文件选择器选择 .gba、.gbc、.gb 或 .zip。读完后自动开始，下次打开应用会继续上次的游戏。
  • 方式二（扫描）：长按「打开」 会扫描「Download 下载目录」、「模拟器共享目录」和你在 11.1 自定义 ROM 文件夹 里添加的目录，列出找到的 ROM 供一键打开；也可在文件管理器里用「打开方式」选择本应用。
  • 方式三（游戏库）：见 第 11 节，先「扫描」再点列表里的游戏。
  • ZIP 加载：把 ROM 直接放进 .zip 即可，无需解压。
  • 第一次打开游戏会请求「所有文件访问」权限，请允许，游戏存档会写到 mGBAx/saves。

3. 基本操作：暂停 / 复位 / 倍速 / 快进

  • 暂停 / 继续：点 暂停 冻结模拟，再点变 继续。
  • 复位：把当前游戏重新开机，不会删除电池存档，但即时存档/未保存的临时进度会丢失（关闭或重置前可设确认）。
  • 倍速：
  • 点 倍速 展开倍速条，可选 1 倍 / 4 倍 / 8 倍 / 16 倍，以及 自定义（输入小数，支持慢动作到 0.25 倍甚至更慢，范围约 0.05–16 倍）。
  • 倍速声音：加速时声音是否一起变速。关闭 → 加速时静音；打开 → 有声音。
  • 音乐原速（不变速）：打开「倍速声音」后还可勾选它，用 WSOLA 时间拉伸把多余音频压进实时播放，音乐保持正常速度、正常音高，不会像磁带那样升调或跳段。
  • 每次启动都会回到 1 倍，不沿用上次倍速。
  • 快进（临时加速）：按住键盘 Tab / 空格，或手柄 右摇杆按下，会临时加速，松开恢复当前倍速。快进速度可在 高级设置 里调（2–16 倍）。

4. 画面与声音

4.1 画质（点「画质」）

  • 画面滤镜：
  • 关闭：原始高清放大。
  • GBA 色彩：模拟 GBA 屏幕偏暗偏绿的真实发色。
  • 灰度：黑白画面。
  • HQ2x / HQ4x / 2xBR / 4xBR：把像素斜边、圆角插值得更平滑，整数缩放时效果最好。
  • 残影：模拟慢响应 LCD 的拖影，和真机液晶一样。
  • 点阵 / LCD3x：模拟老掌机像素格子和三色子像素。
  • 扫描线（平滑）：柔和的逐行变暗。
  • 锐利插值：非整数倍缩放时像素依然干净。
  • 滤镜配合「整数缩放」效果最佳；亮度调节对滤镜同样生效。
  • 帧间混合：开启后让运动画面更顺滑。
  • 双线性过滤：放大时平滑像素边缘。
  • 锁定宽高比：保持 3:2（GBA）/ 原始比例，不拉伸变形。
  • 整数缩放：画面按整数倍放大，避免模糊；与滤镜搭配最佳。
  • 扫描线：叠加扫描线效果。
  • 跳帧：设备跟不上时手动设置跳帧档位；还有 自动跳帧——设备跟不上自动跳、跟得上恢复全帧，优先用这个。
  • 亮度：0–100% 调节画面明暗。

4.2 外部渲染器（自定义着色器）

点「画质」里的 外部渲染器 → 安装渲染器（.glsl），可装第三方单通道 GLSL ES 片段着色器。可用变量：uTex（游戏画面）、vTexCoord（坐标）、uTexSize、uOutSize、uBrightness；常见 RetroArch 命名（TEXTURE/TextureSize/OutputSize/vTexCoord/COMPAT_TEXTURE）会自动适配。

4.3 画面场景（移动 / 缩放）

点「画质」里的 画面场景，可微调游戏画面的 水平位置、垂直位置、缩放百分比，并支持「恢复居中」。适合在带鱼屏或异形屏上把画面摆到舒服的位置。

4.4 声音

在 设置 → 声音 中：

  • 音量：0–150%。
  • 低延迟音频：支持的设备上减少声音延迟（开/关）。
  • 沉浸模式：隐藏状态栏 / 导航栏，全屏玩游戏。
  • 通道音量（GBA 音频 6 路独立调节）：通道 1/2（方波）、通道 3（波形）、通道 4（噪声）、DMA A / DMA B（音乐 / 音效采样），各 0–150%。比如想单独听 BGM 或关掉某路噪声很方便。

5. 虚拟按键与手感

游戏画面上的按键是透明描边，点下去会带一点绿色。

  • 按键布局：左边方向键、右边 B 和更大的 A、左上 L、右上 R、底部中间 SELECT / START。手指按住后稍微滑动，A、B 等键不会松开，松开手指才抬起。
  • 编辑键位：点菜单栏 键位 进入编辑：
  • 单指拖动移动按键；
  • 双指捏合缩放，或用下方滑杆和 ＋ / − 微调（40%–300%）；
  • 先点一下选中某按键，再捏合 / 拖滑杆缩放它；
  • 配置：可新建空配置、复制当前配置、切换 / 删除多套键位布局（至少保留一套）；
  • 重置：恢复默认键位；完成：退出编辑，改动自动保存。
  • 外接手柄：十字键移动，X 是 A，Z 是 B，Enter 是 START（也可在系统里重映射）。

在 设置 → 输入 中微调手感：

  • 触屏振动：关 / 轻 / 中 / 强。
  • 连击方式：
  • 长按 B 键自动连击：短按 B 只按一次（可取消 / 返回）；按住 B 约 0.2 秒后开始连点，B 边框会闪，松开停止。连点是「一帧按下、一帧松开」，游戏才会当成新按键（适合快速翻对白）。
  • 仅用连发键：只用专门的连发键连点。
  • 关闭。
  • 连击速度：次/秒，调节自动连点的频率。
  • 禁用方向键对角：一次只按一个方向，避免斜向误触。
  • 虚拟按键不透明度：调淡或调浓按键（40%–300%）。
  • 虚拟按键开关：可显示 / 隐藏「连发 / 快存 / 快读 / 倍速 / 截图 / 倒带快捷键」等快捷虚拟键。其中 「倒带快捷键（点一次 2 秒）」默认开启，点一下直接回退 2 秒，不用进菜单；在 键位 编辑里可像普通按键一样拖动、缩放，不想用就在这里取消勾选。
  • 倒带快捷键秒数：倒带快捷键：N 秒 / 点一次 可设 1～10 秒（默认 2 秒）。改完后按键上的标签会同步变化，例如设成 5 秒就显示「倒带5s」。
  • C 键 / C2 键（组合宏）：给某个按键绑定「按住时模拟按下的按键组合」，例如一键放必杀。在键位编辑里选中按键后设置。
  • 识别到实体按键时提示隐藏虚拟按键：接上手柄后询问是否隐藏屏幕按键。

6. 即时存档（槽位）

即时存档与游戏内自己的存档是两回事，一共 9 个槽位，适合随时存 checkpoint。

  1. 点 槽位 切换到下一个槽；槽位号后有 ● 表示该槽已有存档。
  2. 点 存档 或 读档，列出 9 个槽：有存档的显示保存时间，空槽显示「空」。
  3. 选中后才会写入 / 读取；读取空槽会提示「没有即时存档」，不会覆盖当前画面。

在 设置 → 存档 中还能开启：

  • 进入游戏时自动读档（上次退出的进度）。
  • 退出时自动存档。
  • 关闭 / 重置时确认，防止误关丢失进度。
  • 定时存档：每隔 N 分钟自动存一次（关 / 每 5、10、15…分钟）。
  • 快存自动轮转槽位（1–9）：每次快存自动换下一个槽，等于自动保留多份进度。

7. 游戏存档、BIOS

  • 电池存档：游戏自己的存档（如《宝可梦》的进度）默认自动写入 mGBAx/saves；若 ROM 同目录已有同名存档，则自动改用同目录那一份（见 11.2）。下次直接打开同一游戏即可继续。菜单栏下方绿字显示的就是当前实际路径，可点击复制。
  • BIOS 导入：点 BIOS 选择 BIOS 文件。GBA BIOS 一般 16KB，导入后需重新打开游戏生效；在 高级设置 里打开「使用 BIOS」与（可选）「跳过 BIOS 启动画面」。
  • 复位：把当前游戏重新开机，不删除任何存档。

在 设置 → 存档 中还能：

  • 删除电池存档（.sav）：删除前会备份为 .bak，并重新载入游戏。
  • 导入 My Boy 存档：选择 My Boy 的 save 文件夹，把老存档迁移过来（显示成功 / 失败数量）。

8. 金手指

点菜单栏 金手指：

  1. 若没有任何作弊码，点 新增。
  2. 填 名称（如「无限金钱」），格式 选 自动识别（最省心，自动判断 GameShark / Pro Action Replay / CodeBreaker 等）。
  3. 代码 框里每行一个，例如：

```

82025838 104E

```

  1. 点确定即添加并生效；列表里勾选即启用，取消勾选即停用。
  2. 长按某条作弊码可删除。

  注意：乱填代码可能导致游戏崩溃或卡死，建议一次只开一两条验证。

9. 倒带

把游戏「往回拨」，救一把手滑或想重来的一段。现在有两种用法，互不冲突。

9.1 一键倒带快捷键

这是新增的快捷方式，推荐日常使用。虚拟按键上多了一个 「倒带2s」 键，默认就显示在屏幕上：

  • 点一下立即回退 2 秒，不弹菜单、不用两步，手滑了随手一点就能重来。
  • 秒数可改：设置 → 输入 → 倒带快捷键：N 秒 / 点一次，可选 1～10 秒（默认 2 秒）；按键标签随之变为「倒带Ns」。
  • 这个键与普通按键一样，可在 键位 编辑里单指拖动、双指捏合缩放；不想用就在 设置 → 输入 → 虚拟按键开关 里取消勾选「倒带快捷键（点一次 2 秒）」。
  • 从旧版本升级上来时会自动帮你开启这个键一次；之后你手动关掉就不会再自动打开。

  它和菜单倒带走的是两条独立通道：点快捷键只执行「一次 N 秒」，不会展开秒数条，也不会改动倒带条上当前选中的秒数。

9.2 原来的倒带条（完全保留）

  • 点菜单栏 倒带（或掌机皮肤顶部的 ⏪）展开秒数条，可选 1 分钟 / 45 / 30 / 15 / 12 / 9 / 6 / 3 秒 倒回，或 持续倒带（按住）：按住按钮持续往回退，松手停在那一帧。
  • 菜单「倒带」按钮单击仍是展开秒数条，掌机皮肤 ⏪ 的行为也没变。
  • 倒带记录是边玩边生成的，刚开局还没记录时会提示「还没有倒带记录」。
  • 硬核模式（若开启）下倒带不可用。

10. 联机（云端大厅）

两边各跑同一款 ROM，一边创建房间、一边加入，即可双人联机（如《精灵宝可梦》交换 / 对战）。

  1. 先打开同一个游戏，再点菜单栏 联机 → 云端大厅。
  2. 已注册过账号：直接在「邮箱」填邮箱、「密码」填原密码，然后点 云端创建（拿房间号，你是 1P）或 云端加入（再填对方给你的「房间号」）。
  • 首次注册后账号密码会自动记住，之后免验证码直接登录。
  • 全程不会收到任何邮件。
  1. 全新账号：先点 获取验证码（同一邮箱 5 分钟只能发一次），到邮箱查收验证码，填好验证码 + 邮箱 + 密码完成注册，再创建 / 加入。
  2. 两边保持 1 倍速、打开同一个游戏，连接成功后即可联机。
  3. 其它按钮：重新连接中继（断线后重连，需先有房间）、断开、联机自检（先填邮箱与密码做连通性测试）。
  4. 不确定怎么填，点大厅里的说明文字可随时查看帮助。

  联机依赖内置云中继；若长时间连不上，多为网络 / 防火墙问题，先各自用「联机自检」排查。

11. 游戏库

点菜单栏 游戏库：

  • 扫描：查找 Download 目录、模拟器共享目录，以及你添加的自定义 ROM 文件夹（见 11.1）。
  • ROM 文件夹：直接打开文件夹管理对话框（与 设置 → ROM 文件夹 是同一个）。
  • 打开…：用文件选择器直接选 ROM。
  • 收藏：把常玩的游戏加星，收藏列表单独成组，打开更快。
  • 上次游戏：一键回到上次玩的那款。
  • 带存档的游戏会在名字后标注 [同目录有存档]。
  • 空列表时会提示把 .gba/.gb/.gbc 放进 Download 目录、添加自己的文件夹，或用「打开方式」启动。

11.1 自定义 ROM 文件夹

入口：设置 → ROM 文件夹，或 游戏库 → ROM 文件夹。

  1. 点 从系统选择文件夹…，在系统文件夹选择器里选中放游戏的目录；也可点 手动输入路径，直接填绝对路径（例如 /sdcard/ROMs）后确定。
  2. 可以同时添加多个文件夹；列表里每个目录右边都有 移除，随时可删。
  3. 点 扫描 ROM 立即重新扫描，或回到游戏库点 扫描。

使用要点：

  • 自定义文件夹里的游戏优先扫描、排在最前面；扫描最多向下找 3 层子目录，一次最多列出 200 个 ROM。
  • 系统文件夹选择器会同时申请该目录的持久读取权限。若个别第三方文件管理器给不出真实路径、提示「系统无法给出该文件夹的真实路径」，改用 手动输入路径 添加即可。
  • 自定义目录扫描依赖系统的 「所有文件访问权限」，首次使用时请允许。
  • 不必再把 ROM 复制到 Download 目录；原来的公共目录扫描也照常保留。

11.2 游戏和存档放同一个文件夹

这是自定义文件夹最实用的用法：把游戏文件和存档放在同一个目录，模拟器会自动认出来。

  • 目录举例：/sdcard/ROMs/口袋妖怪.gba（游戏）、/sdcard/ROMs/口袋妖怪.sav（电池存档）、/sdcard/ROMs/口袋妖怪.ss1（即时存档槽 1），放在同一个文件夹即可。
  • 命名规则：存档与 ROM 同名、同目录，只换扩展名。电池存档支持 .sav、.srm、.sa1～.sa4；即时存档支持 .ss0～.ss9（常用 .ss1）。
  • 自动识别：加载游戏前会检查同目录有没有同名存档，有的话电池存档和 9 个即时存档槽位整体切到 ROM 同目录；扫描列表和游戏库会标注 [同目录有存档]，菜单栏下方绿字路径也会指向这里。
  • 核心会优先打开已经存在的那份（.sav → .srm → .saN），不会在同目录凭空新建一个空 .sav 把真存档盖掉。
  • 兼容老存档：同目录没有存档时，仍用原来的公共目录 mGBAx/saves 和私有 states，升级后旧存档不会丢。
  • 想让新游戏从一开始就存到 ROM 同目录：到 设置 → 存档 打开 「新游戏的存档也放 ROM 同目录」（该文件夹需可写）。

  注意：放在 ROM 同目录的存档不纳入应用内「备份」和 WebDAV 云同步（这两处只扫描公共存档目录）。换机或同步时请手动复制整个文件夹，或关掉同目录存档让它回到公共目录。

12. 皮肤

点菜单栏 皮肤：

  • 皮肤样式：
  • 经典（半透明线条）：默认透明描边按键。
  • 掌机：竖屏走 Pizza Boy 风、横屏走 GBA 掌机风，更有实体机味道。
  • 机身颜色：切换掌机外壳配色（应用后即时生效）。
  • 整包皮肤（PNG）：
  • 点 导入皮肤包（zip），zip 内放按键 PNG：dpad / a / b / l / r / select / start；加 _p 后缀为「按下」贴图（如 a_p.png）；加 bg_portrait.png、bg_landscape.png 作背景。
  • 也可从 mGBAx/skins 目录批量导入；删除选中皮肤 可移除。
  • 选「无（默认绘制）」回到内置绘制。

13. 贴纸

在画面上叠加图片（攻略图、表情包都行），最多 10 张。

  • 添加贴纸：从 mGBAx/stickers 目录选图片，或直接选一张本地图片，自动进入编辑模式。
  • 贴纸编辑模式：拖动移动、双指捏合缩放，摆好后退出即可（位置会记住）。
  • 清除全部贴纸：一键清空。
  • 贴纸只是覆盖层，不影响游戏操作；图片读取失败会有提示。

14. 每游戏设置

有些游戏你想单独调画质 / 倍速 / 存档类型，而不影响全局——用 每游戏设置（菜单栏 → 每游戏设置）：

  • 滤镜、倍速、存档类型、GB 调色板：仅对当前这款游戏生效，会覆盖全局默认。
  • 恢复全局默认：清掉本游戏的专属设置，回到全局配置。
  • 打开游戏时，菜单栏下方会显示「本游戏设置：…」提示当前生效的覆盖项。

15. 设置总览

点菜单栏 设置，进入设置中心，里面分八项：

  1. 屏幕方向：横屏 / 横屏（反向）/ 竖屏 / 竖屏（反向）/ 自动旋转 / 系统默认。
  2. 声音：见 4.4。
  3. 输入：见 第 5 节；这里还能设 倒带快捷键秒数（1～10 秒，默认 2 秒）。
  4. 存档：见 第 6、7、17 节；可开「新游戏的存档也放 ROM 同目录」。
  5. 高级：见 第 16 节。
  6. ROM 文件夹：添加 / 移除自定义游戏目录，见 11.1。
  7. 扫描 ROM：等价于长按「打开」的目录扫描。
  8. 帮助：内置一段速览帮助（倍速、画质、金手指、调试、补丁、同步、联机、截图的位置和用法）。

16. 高级设置

点 设置 → 高级：

  • 使用 BIOS（需先在菜单导入）：开启后走导入的 BIOS；隔壁 跳过 BIOS 启动画面 可跳过开机动画直接进游戏。
  • 游戏时钟（RTC 卡带）：
  • 实时时钟：跟随手机时间（《宝可梦》日夜系统用它）。
  • 固定时间：手动设一个日期时间，用于触发特定时间事件。
  • 偏移时间：手机时间 + 偏移分钟。
  • 卡带振动（轰隆声）：需游戏支持的振动卡带才有效。
  • 太阳能仿真（我们的太阳 / Boktai）：
  • 开关 + 阳光强度 0–10 滑杆；
  • 阳光来源：用音量键实时调节，或手机的感光器（环境光越强阳光越足）；
  • 开启后游戏里的光照随你调节变化。
  • SGB 边框：支持 Super Game Boy 的游戏显示专用边框画面。
  • 倾斜传感器卡带：玩《扭转世界》（GBA）和《科比摇摆》（GB）这类感应卡带时，用手机姿态模拟卡带里的传感器（倾斜手机即可）。
  • GIF 浮球（录制开关悬浮在画面上）：开启后画面上有个随时开 / 停 GIF 的小球，比进菜单更方便。
  • 游戏运行通知（防后台清理）：开启后状态栏常驻「游戏运行中」通知，降低被系统杀后台的概率。
  • GB 调色板：14 种单色 GB 配色（默认 / 原版 / 灰度 / 棕色 / 深棕 / 红 / 绿 / 深绿 / 蓝 / 深蓝 / 橙 / 黄 / 粉彩 / 反转），换了立即生效。
  • 快进速度：2–16 倍，决定 Tab / 空格 / 右摇杆快进的力度。

17. 存档设置

点 设置 → 存档：

  • 游戏保存类型：自动检测或手动指定（Flash / SRAM / EEPROM 等）；遇到存档失效时可手动改。
  • 进入游戏时自动读档：上次退出进度自动恢复。
  • 退出时自动存档：关游戏前自动写一次电池存档。
  • 关闭 / 重置时确认：防误触丢失进度。
  • 新游戏的存档也放 ROM 同目录：开启后，即使同目录还没有存档，新游戏的电池存档和即时存档也直接写到 ROM 所在文件夹（需该文件夹可写）；关闭时沿用公共目录。详见 11.2。
  • 自动使用 IPS / UPS / BPS 补丁：把补丁改成和 ROM 同名（扩展名保留，如 游戏.ups）放在同一文件夹，进游戏时自动应用（汉化、改版常用）。
  • 删除电池存档（.sav）：删除会先备份为 .bak 再重载；没有存档会提示。
  • 导入 My Boy 存档：选 My Boy 的 save 目录批量迁移。

18. 备份与恢复

点菜单栏 备份：

  • 备份到文件（设置 + 存档 + 状态）：把当前键位 / 画面 / 声音等设置、电池存档、即时存档打包成一个备份文件，方便换机或重装前保存。
  • 从备份文件恢复：选备份文件还原，进度与设置一并回来。
  • 操作成功 / 失败都有提示；建议重装或换手机前先备份一次。
  • 范围提醒：「备份」只收集公共存档目录里的电池存档和即时存档。若启用了 ROM 同目录存档，这些文件需要自己手动复制整个文件夹来备份。

19. AI 画面翻译

点菜单栏 翻译（需先配置）：

  1. 设置 Gemini API Key：在 设置 → 输入 之外的专属入口（或翻译面板里）粘贴 Gemini API Key（免费档可用）。
  2. 选 目标语言（如中文）。
  3. 回到游戏点 翻译，应用会识别画面上的文字块并翻译覆盖，提示「已翻译 N 个文本块」；点击画面 关闭翻译层。
  4. 没识别到文字 / 没填 Key / 翻译失败都会有对应提示。

  适合玩英文 / 日文原版 RPG：把对白、菜单译成中文再点掉，沉浸感拉满。

20. 截图与 GIF 录制

  • 截图：点菜单栏 截图，图片存到 Pictures/mGBAx（可在设置里改截图格式）。也可在 设置 → 输入 开启 双击屏幕截图，游戏中双击即存。
  • GIF 录制：点菜单栏 GIF 开始录制，再点一次 停止 GIF 结束，文件自动保存；或在 高级设置 开 GIF 浮球，用悬浮球随时开始 / 停止。适合录一段搞笑操作发群里。

21. 调试工具

点菜单栏 调试（移植自专业调试套件，进阶玩家向）：

  • 内存查看器：十六进制内存浏览，搜索 数值（首次选 = 输入要找的数，再逐步缩小）、点击十六进制区直接改字节（改值前建议先暂停游戏），可拿来做「内存型金手指」。
  • 图层查看器（BG）：查看背景图层，显示大小 / 优先级 / 图层地址 / 映射地址；模式 3/4/5 会标注位图信息。
  • 贴图查看器（OAM）：查看当前画面里的精灵贴图，显示坐标 / 尺寸 / 图块 / 调色板 / 翻转 / 优先级。
  • 调色板查看器：查看背景 / 贴图调色板，显示每个颜色的 RGB 与内存地址。

  图层 / 贴图 / 调色板查看器（PPU 相关）仅支持 GBA 游戏，GB / GBC 下会提示不可用。

22. 常见问题与提示

  • 游戏打不开 / 黑屏：确认 ROM 没损坏；试试在「每游戏设置」改存档类型；必要时导入 GBA BIOS 并在高级里开「使用 BIOS」。
  • 没声音：检查「声音」里音量不是 0；试开关「低延迟音频」；通道音量别误调到 0。
  • 存档丢了：电池存档在 mGBAx/saves，删除前会留 .bak；换机前用「备份」打包。
  • 想多设备同步存档：在存档设置里配 坚果云 WebDAV（注册后到「账户信息 → 安全选项 → 添加应用密码」生成 16 位应用密码，账号填邮箱、密码填应用密码，服务器地址默认即可），开「进出游戏时自动同步」，按修改时间取较新的 .sav。
  • 联机连不上：两边同一游戏、都 1 倍速；用「联机自检」先测账号与网络；卡住点「重新连接中继」。
  • 按键误触 / 手感差：进「键位」重排并调不透明度；手柄用户开「识别实体按键时隐藏虚拟按键」。
  • 画面糊 / 锯齿：开「整数缩放」+ 选 HQ2x / 4xBR 等插值滤镜；非整数屏可用「锐利插值」。
  • 权限提示：首次打开游戏会请求文件访问，请允许，否则存档写不进去。
  • 自己建的文件夹扫不到游戏：确认已在 设置 → ROM 文件夹 添加该目录、路径是真实绝对路径（系统选择器给不出路径时改用「手动输入路径」），并允许「所有文件访问权限」；添加后点「扫描 ROM」。子目录最多向下找 3 层。
  • 同目录的存档没被读到：存档必须和 ROM 同名、同目录（游戏.gba ↔ 游戏.sav / 游戏.ss1），扩展名用 .sav / .srm / .sa1～.sa4 / .ss0～.ss9，且文件不能是 0 字节。命中后游戏库会标注「[同目录有存档]」，没标就是没认出来。
  • 倒带快捷键不见了 / 想改秒数：到 设置 → 输入 → 虚拟按键开关 重新勾选「倒带快捷键（点一次 2 秒）」；秒数在「倒带快捷键：N 秒 / 点一次」里改（1～10 秒）。菜单「倒带」和掌机 ⏪ 的用法没变，仍是展开秒数条。
